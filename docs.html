Installation & Developer Exports

Requires FXServer artifact 5181+, oxmysql (for PrismScan, VaultNet & HeatHUD persistence), and OneSync enabled.

1. Server Load Order (server.cfg)

ensure oxmysql
# Framework (qbx_core / qb-core / es_extended) + optional ox_lib / ox_target / ox_inventory

ensure sc_vehscan
ensure sc_wanted
ensure sc_launder
ensure sc_carjack

2. Database Setup

Import the SQL files inside each resource's sql/install.sql folder:

resources/sc_vehscan/sql/install.sql
resources/sc_launder/sql/install.sql
resources/sc_wanted/sql/install.sql

3. Open Bridge Customization

Every resource keeps config.lua, locales/*.lua, shared/*.lua, and bridge/*.lua unlocked in escrow_ignore so you can adapt custom inventories, notifications, key scripts, or police dispatch systems without waiting for updates.
